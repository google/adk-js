**Problem**: Developers may want to run "memoryless" agents which discard history at every step, but standard compactors only support truncating limits or tokens.

**Solution**: Add `NullContextCompactor` which purges the session.events array, enabling memoryless interactions cleanly natively via the Context Compactor layer.
