# Security

Report a suspected incident within one hour, through the security portal. An
incident is any lost device, any credential you believe has been exposed, and
any message you acted on before realising it was a phishing attempt.

Reporting late is the thing that turns a small incident into a large one. There
is no penalty for reporting something that turns out to be harmless, and that
is deliberate.

Customer data never leaves an approved system. Copying it to a personal device,
a personal account, or an unapproved tool is an incident in itself and is
reported the same way.
