# @google/adk-integrations

Reserved for third-party integrations for [Agent Development Kit (ADK) for
TypeScript](https://github.com/google/adk-js). It has no public API yet — the
package currently exports nothing but its own version string.

**Do not depend on this package.** Versions up to and including `1.5.0` were
published to npm as an empty placeholder. It is now marked `private` and is no
longer part of the release train; it will be published again only once it has
something to export.

Everything ADK offers today lives in
[`@google/adk`](https://www.npmjs.com/package/@google/adk), with the CLI and dev
UI in
[`@google/adk-devtools`](https://www.npmjs.com/package/@google/adk-devtools).
